## Reading the classifications

**V — verified and preserved:** retained controlled/source coverage, exercised by the current suite where applicable. **R — demonstrated defect repaired:** actual behavioral red followed by minimal source repair and passing controlled tests. **L — source verified with acceptance limitation:** the decision path is established, but controlled leaves or source evidence cannot prove the live outcome. **D — exact external dependency:** the necessary input is named below. **U — intentionally unsupported/fail-closed:** missing provenance/protocol prevents enabling a behavior. Several classifications can apply to one requirement because a verified managed decision does not complete physical/native/server acceptance.

Evidence anchors: **LOCAL17** is the earlier `W110_CONTINUOUS_LOCAL_GATE_20260928/summary.json`,17/17 groups and1880 unchanged working-source inputs. The later cleanup/whole-file-compiler extension and the recovered mount/Flightor continuation have separately named results in the final checkpoint and evidence manifest; do not apply the earlier result to subsequently edited source. **RET** is the retained `PaladinDecisionRegressionTests` plus actual Singular compilation; **SUPPORT** is `PaladinSupportRegressionTests` and the W110 support/collection/native-aura records; **GROUP** is `GroupEngagementRegressionTests`; **QUEST** is the retained QuestRecovery/Wholesome/adapter/pickup/observation/completion suites; **WORLD** is the retained native/elevator/navigation/terrain and Wholesome movement fixtures. Passing a fixture whose leaves are controlled is not a live-game certificate.

**D1 — original client/native runtime:** the approved executable hash/version and an authorized nonproduction development session; frame/control/actor/target/object lifetime evidence across native calls, control/vehicle changes, transport transforms, aura/cast reads, target acknowledgement and memory failure. Repeated reads and static IDA do not establish atomicity or live game success. A same-version differently patched image is not automatically supported.

**D2 — server and multiplayer:** identified TC335/AC commit/configuration, realm spell/quest/item scripts, packet/event outcomes, real proc/stack/DR/immunity/Forbearance/lockout/aura magnitude, roster/range/death and cross-Paladin state. Source capability is not proof of this realm's result.

**D3 — causal request/response protocols:** first gossip/menu attribution, generic ground-cursor request provenance, optional legacy frame actions and broader inventory/cursor transfers. Need supported identity/lifetime/dispatch-to-response contracts. Text/entry/slot/index/content/timing equality and local execution receipts cannot replace them.

**D4 — realm data and admitted recipes:** versioned/hashes/source provenance, prerequisite/chain/phase/objective mapping and supported materializers for scripted escort, raw slots, object/ground item actions, BelowHp thresholds and legacy helper families. Unsupported records remain excluded rather than becoming ordinary kill/use behavior.

**D5 — physical world and supervised routes:** map/mesh/terrain/collision revisions, safe Z/cliff/ledge/water/shore/cave/door/bridge/elevator/taxi paths, landing support, mount/remount transitions, hostile envelopes and demonstrated safer ranged-pull retreat. Coordinate validity/LOS/mesh success is insufficient. DensePullIsolationValidated stays false.

**D6 — independent acceptance:** an independent review and authorized supervised original-client/server scenario evidence for the complete integrated workflow and any performance/optimality assertion. This agent's own review and automated fixtures are not independent acceptance.
