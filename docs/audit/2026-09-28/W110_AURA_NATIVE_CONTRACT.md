## API data available and not established

The returned shared-owner decompilation emits name, rank, icon, count, dispel kind, duration, expiry, caster, stealable/consolidation indications and spell ID on its successful eleven-value path. The native instruction window corroborates the load/output positions necessary for the timer repair. The separate reduced-information branch is decompiler evidence and must not be promoted to a complete instruction audit.

No arbitrary externally talent-adjusted aura magnitude is one of those eleven ordinary returns. This is **not** proof that no amount can ever be observed anywhere in the original client. In particular, pinned TC/AC headers name bit0x40 as an optional effect-amount-sent flag. Establishing whether/how a specific realm supplies those values, where this exact client stores them, their caster/rank/modifier binding, and a reliable current observation is separate work. The current24-byte managed AuraInfo has no amount field. No speculative field, pointer or strength comparison was added.

`WoWAuraCollection.GetTotalAuraModifier` adds spell-effect base points from local spell data. That calculation is not a proven observation of external effective strength and is not promoted to one by this review. Existing conservative Might/Shout and same-family coverage behavior remains; only its incorrect lifetime interpretation is repaired after regression-first proof.

## Core corroboration, not a substitute client contract

Primary TC3.3.5 commit `8fda442f6c30ca21a622638063ab8b28376f1b25`, secondary AC commit `8337a378ac325e62a6a91e00c6a5e944205e8536`: `src/server/game/Spells/Auras/SpellAuraDefines.h` names0x20DURATION and0x40ANY_EFFECT_AMOUNT_SENT. Exact reference hashes are in the new evidence manifest. These sources are pinned core implementations, not the user's realm identity or a claim that every wire flag equals every client semantic.

The legacy public enum name `NoDuration=32` is therefore not sufficient authority for the timer. To preserve binary/serialization compatibility, its numeric value and all other enum members remain. The bounded repair follows the independently observed **signed Duration field** rather than renumbering flags or guessing passive/cancelability/caster semantics.
