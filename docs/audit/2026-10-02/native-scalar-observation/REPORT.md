# Native scalar observation

Missing native bytes could become a valid map zero or enabled object flags. `LocalPlayer.MapId` used the generic typed reader, which returns default for incomplete transfer; `CurrentMap` could then construct/cache that fabricated map. `WoWObject.IsValid` also swallowed cancellation during its type read. These are shared inputs used by navigation, questing and spell/item observation ownership.

The repair keeps generic `Memory.Read` compatibility intact. The selected getters instead require an exact four-byte observation from their captured object/memory/process owner. Complete map zero and disabled/invalid type observations keep their original meaning. Missing or partial bytes and replaced owners produce controlled UNKNOWN, while direct/wrapped cancellation and a closed current process handle still propagate. The map cache publishes only after its actor and map are revalidated across metadata construction; a nested current publication is retained instead of overwritten.

The changed native addresses and widths are the existing original build12340 constants: MapId0xBD088C, object flags at base+0xBC and type at base+0x14, each four bytes. No native ABI, generic reader default, gameplay policy or server behavior changes. The actual byte reader, cache, type conversion, scalar properties and map-cache owner execute in the regression fixture; only byte transfer, process/world references, object base addresses and map construction callbacks are controlled. The test does not open a game process.
