## Design

Replace the old fixed-five-yard interaction/sleep loop with an owned action that selects a valid loaded object, reuses the proven grounded approach, revalidates the original actor/object/map/behavior and existing native usability observations, submits one interaction, then waits for separately observed typed quest progress. Recovery and per-GUID attempts remain bounded; static coordinates are travel hints and never substitute for a loaded object.

Keep the existing loot constructor and protections of GroundLootApproach. Add an explicit direct-use constructor that has its own subject selector and owner admission, without clearing a loot or transport owner's POI. Existing CanUse/CanUseNow ABI is verified against the read-only original build12340 image before reuse; no new offset or server behavior is introduced.
